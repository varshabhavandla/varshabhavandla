# Cover letter writer

## Inputs
JD, the user's resume/profile facts, company name + one specific thing about the company (ask, or from a page the user provides), hiring manager name if known.

## Structure (250-300 words, 3-4 short paragraphs)
1. Hook: the role + the single strongest relevant result, with a number the user confirmed.
2. Proof: 2 achievements mapped to the JD's top two needs.
3. Why this company: one specific, verifiable reason - not "innovative leader".
4. Close: availability, a concrete next step, and (only if the user wants) work-authorization sentence.

## Rubric (self-check before showing; revise until all pass)
- [ ] Under 300 words, no filler openers ("I am writing to apply...")
- [ ] Every claim is traceable to the resume/profile; no invented numbers
- [ ] Mentions the company and role by name; not reusable for another employer unchanged
- [ ] 2 JD needs answered with evidence, not adjectives
- [ ] No pronoun-heavy rambling, no apologies for gaps, no salary talk
- [ ] Tone: confident, plain, specific

## Rules
Offer one draft and one alternative opening line, not five variants. Placeholder anything unknown as `[ask user: ...]`. Do not claim visa/work authorization facts the user hasn't stated.
