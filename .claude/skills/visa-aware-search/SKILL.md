# Visa-aware search (F-1 students)

General education only - **not legal advice**. Rules change: always have the user confirm specifics with their school's DSO (Designated School Official) and, for sponsorship decisions, an immigration attorney. Check official sources (studyinthestates.dhs.gov, uscis.gov, the school's international office) before stating any date or limit.

## Concepts to explain (verify currency before relying on them)
- **CPT:** authorized by the DSO, employer-specific, tied to the curriculum (e.g. a practical-training course like IWU's UNV-501); needs the offer details before authorization. Long full-time CPT use can affect OPT eligibility - ask the DSO before accepting full-time CPT.
- **Post-completion OPT** (typically 12 months) and **STEM OPT extension** (24 months) for eligible degrees; the STEM extension requires an E-Verify employer and a training plan (Form I-983). OPT has an unemployment-day limit - track days.
- **Application windows** for OPT are tied to the program end date; the DSO recommends and the student files with USCIS.
- **H-1B** is employer-sponsored and cap-subject with a registration window typically in spring; employers decide whether to sponsor.

## Steps
1. Ask: degree/program end date, STEM-designated or not, current work authorization stage, DSO contact known?
2. Build the employer filter: prefer employers that state sponsorship support, are E-Verify enrolled (needed for STEM OPT), and have sponsored in public data (e.g. DOL LCA disclosure data via myvisajobs/h1bdata - note these are third-party summaries).
3. Application answers: be truthful and short - e.g. "Currently authorized to work via F-1 CPT/OPT; will require sponsorship in the future" - confirm wording with the DSO. Never claim citizenship/permanent authorization.
4. Put the DSO and attorney check-ins on the timeline in `job-search-roadmap`.
